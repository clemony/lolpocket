# Decisions

Decision pages record choices that future work should preserve, question, or deliberately replace.
They are useful when a decision is not obvious from the final code shape.

Write a decision page when a trade-off affects future implementation options. Keep the reasoning crisp: what changed, why this path won, which alternatives lost, and what would justify revisiting it.

## Suggested Format

- Decision: one sentence.
- Context: the pressure or constraint that led to the choice.
- Consequences: what this enables and what it costs.
- Revisit when: concrete signals that the decision no longer fits.
